# Library Management System API

Course project for SDEV 3310 (API Design and Development). The project grows one assignment at a time, and each assignment has its own branch that builds on the previous one. `main` is the shared starting point.

| Branch | Assignment | Contents |
|---|---|---|
| [`assignment-1`](https://github.com/zarekcodes/assignment-1/tree/assignment-1) | Assignment 1 | API foundation, data models, and validation |

Setup and run instructions are in each branch's README.
